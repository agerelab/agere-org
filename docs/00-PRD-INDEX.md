## Platform contracts (binding on every PRD)

- **Authorization:** server-side through the `authz` module, following PRD-04 §6. No module-local permission models. UI visibility is never the source of truth.
- **Tenancy:** `organization_id` on every organization-scoped row, query and event. The request-context organization comes from the URL slug (PRD-02 §6.2). User-scoped identity events carry none (PRD-00b §6).
- **Events & audit:** cross-module state changes go through `events.publish()` inside the transaction; audit rows are written in the same transaction (PRD-00b D2).
- **Time:** the `due` shape (PRD-00b §6.1) and one timezone rule: user → organization default → Asia/Jakarta (PRD-12 §5.2).
- **Work ownership:** modules with assignable work implement the Work Ownership interface (PRD-03 §6.3).
- **Information architecture:** organization administration lives under **Organisasi** (Umum, Anggota, Tim, Akses, Aplikasi, Audit). **Pengaturan** is personal only. Both are reached through one rail item, **Kelola** (UI-01 v2.2; still one door, C-07). Rail order follows daily usage: **Desk · Space · Chat · Doc · Agen**, then Panduan, Kelola, account.
- **Naming:** display names may change; internal ids never do. Glossary: **Space** = a container of projects (C-18); app id `space` is unchanged and covers spaces, projects, boards and tasks (containers `space.space`, `space.project`); units: "space", "proyek", "tugas"; **Desk** = the personal work area (Kotak masuk, Permintaan, Tugas saya), not an app id; app id `chat` = **Chat** (PRD-14); app id `agent` = **Agen** (PRD-17). The sales glossary (Menang / Kalah, Tindak lanjut, Panas / Hangat / Dingin, Lead, Deal, Pipeline) is withdrawn with PRD-05 (C-16).
- **Money:** amounts are IDR by default (organization-level currency), formatted for the viewer's language — `IDR 49,000` (English) / `Rp49.000` (Bahasa Indonesia) — via `Intl.NumberFormat(locale, {currency: "IDR"})` (UI-01 v2.5 "Bahasa & format"; D45).
- **Languages:** English (default) and Bahasa Indonesia; user preference → organization default → English; user content is never translated (D45, UI-01 v2.5).
- **App homes (C-21):** there is no org-level Ringkasan. Each rail section opens its most-used screen: Desk › Kotak masuk, Space › the last visited space (D46; was Semua proyek), Doc › Semua Doc, Agen › Skill agen. Page headers follow one pattern: title, one sentence, secondary actions, at most one primary action (UI-01 v2.1).
- **Personal data:** readable PII only in identity tables; retention per PRD-13.
