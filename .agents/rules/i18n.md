# i18n (D45, UI-01 "Bahasa & format", TECH-01 F16)

- Two languages: **English (default, source catalog)** and **Bahasa Indonesia**.
- Every system string goes through `t()` from `src/i18n`. **No UI string written in a component.**
- A new key is added to **both** `src/i18n/en.json` and `src/i18n/id.json` in the same PR
  (`tests/lint/i18n.test.ts` checks key and placeholder parity).
- User content is never translated. Events and audit store codes and ids, never sentences.
- Locale order: user preference → organization default → English. Emails and notifications use
  the **recipient's** locale.
- Dates, times, numbers and money only through `src/i18n/format.ts` (day before month in both
  languages; IDR by default). Exports and APIs use ISO 8601.
- Copy: sentence case, verb + object ("New task" / "Tugas baru"); language names in their own
  language ("English", "Bahasa Indonesia"); "Anda" in Indonesian.
